# Experiment 2 — Version Control Operations Using Git

This folder is designed to sit beside the course portal's `index.html` as `exp2/`.

## Files
- `exp2.txt` — full experiment in lab-journal format.
- `git_commands.sh` — copyable Git Bash command sequence; run commands step-by-step and replace placeholder values.
- `exp2.json` — title, description, and official links.
- `README.md` — this file.

## Important
The commands create a local sample repository. When connecting to GitHub, replace `YOUR-USERNAME` with your actual GitHub username and use the exact remote URL shown by GitHub. Do not share passwords or verification codes.

The Git commands are instructional and should be executed step-by-step in Git Bash or a terminal.
