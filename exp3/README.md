# Experiment 3 — Continuous Integration using Jenkins

This folder contains the journal write-up and sample source files for Experiment 03.

## Files
- `exp3.txt` — experiment journal and procedure
- `HelloJenkins.java` — basic Java example
- `MultiplicationTable.java` — Java multiplication table using a command-line argument
- `multiplication_table.py` — Python multiplication table using a command-line argument
- `ci.yml` — sample GitHub Actions workflow that runs the Python example

## Notes
Jenkins commands depend on the operating system of the Jenkins agent. The journal shows Windows batch and Unix shell alternatives. Make sure Java/Python are installed on the agent and available in `PATH`.
